# DateTimePicker

Ein Visual-Studio-Projekt zur Einführung in die Verwendung des DateTimePicker-Steuerelements innerhalb einer grafischen Benutzeroberfläche.

## Beschreibung

Das Projekt **DateTimePicker** beschäftigt sich mit den Grundlagen der Datum- und Zeitauswahl in C#.

Im Mittelpunkt stehen die Verwendung des DateTimePicker-Steuerelements, die Auswahl und Verarbeitung von Datums- und Zeitwerten sowie die Integration dieser Funktionen in eine grafische Benutzeroberfläche.

## Funktionen

- Darstellung eines DateTimePicker-Steuerelements
- Auswahl von Datumswerten über einen Kalender
- Eingabe und Verarbeitung von Datums- und Zeitangaben
- Formatierung der angezeigten Datumswerte
- Zugriff auf ausgewählte Werte
- Grundlagen der ereignisgesteuerten Programmierung

## Technologien

- Microsoft Visual Studio
- C# / .NET
- Windows Forms (WinForms)
- Visual-Studio-Projektmappe (.sln)

## Installation und Ausführung

1. Repository klonen:

   ```bash
   git clone https://github.com/samad-pour/DateTimePicker.git
   ```

2. Die Datei `DateTimePicker.sln` in Visual Studio öffnen.
3. Das Projekt erstellen.
4. Die Anwendung mit `F5` starten.
